# SLV breeding framework analysis scripts

This repository contains the analysis scripts for the manuscript:

**A Systems Life View framework for multi-trait coordination breeding in secondary-metabolite-specialized crops: mathematical derivation and cross-system computational validation**

## Requirements
- Python 3.14
- pandas 2.5.3
- numpy 2.5.3
- scipy 1.18.1
- R 4.3.1 (for BLUP estimation, lme4 package)

## Files
- `SLV_analysis.py`: Main script for SLV model construction, ΔS calculation, time-split validation, and Pareto front analysis.
- `test_single.py`: Script for single-trait selection comparison.
- `A_ge_results.xlsx`: Calculated genotype–environment adaptability A(g,e) results.
- `SLV_Detailed_Predictions.xlsx`: Detailed SLV prediction results.
- `Table1-4.xlsx`: Source data for tables in the manuscript.

## Data
Soybean RIL genotype and phenotype data are available in Supplementary Data S1 of the manuscript.
